# انتشار روی لیارا — قدم به قدم

این راهنما فرض می‌کند که با **پنل** لیارا کار می‌کنی، نه ترمینال.

هر چیزی که از سمت کد لازم بود آماده است. کاری که می‌ماند فقط چیزهایی است که به
حساب و اعتبار خودت نیاز دارد.

> **یک نکته درباره‌ی نام فیلدها:** من به پنل لیارا دسترسی ندارم و سایتشان از
> جایی که من اجرا می‌شوم باز نمی‌شود. اسم فیلدها را از مستندات عمومی‌شان برداشته‌ام.
> اگر روی صفحه چیز دیگری نوشته بود، همان درست است — بگو تا اصلاح کنم.

---

## ۱. برنامه را بساز

توی پنل لیارا یک برنامه‌ی جدید از نوع **Node.js** بساز. (خود صفحه هم می‌گوید از
Express پشتیبانی می‌کند — همان چیزی که این برنامه با آن نوشته شده.)

بعد **شناسه‌ی برنامه** را می‌خواهد. هرچه بنویسی می‌شود آدرس سایتت:

```
studybuddy   →   https://studybuddy.liara.run
```

فقط حروف انگلیسی کوچک، عدد و خط تیره. بعداً سخت عوض می‌شود، پس یکی را بردار که
راضی باشی؛ دامنه‌ی اختصاصی را هر وقت خواستی می‌شود روی همین اضافه کرد.

### فایل `liara.json`

این فایل توی مخزن هست و لیارا موقع انتشار می‌خواندش. با همان چیزی که خودِ لیارا
تولید کرده ساخته شده، به‌علاوه‌ی دیسک:

```json
{
  "app": "studybuddy",
  "port": 3000,
  "build": { "location": "iran" },
  "node": { "version": "22" },
  "disks": [{ "name": "data", "mountTo": "/app/data" }]
}
```

| فیلد | چرا |
|---|---|
| `app` | شناسه‌ی برنامه در لیارا |
| `port` | برنامه روی ۳۰۰۰ گوش می‌دهد |
| `build.location` | جایی که ساخته می‌شود؛ همان مقدار پیش‌فرض خودِ لیارا |
| `node.version` | باید ۲۲ به بالا باشد — پایین‌تر بالا نمی‌آید |
| `disks` | جایی که پایگاه‌داده می‌نشیند و از انتشار بعدی جان سالم به در می‌برد |

**نسخه‌ی نود ۲۲.۵ به بالا لازم است.** پایگاه‌داده از SQLite داخلی خود نود استفاده
می‌کند که از ۲۲.۵ اضافه شده. اگر پایین‌تر بالا بیاید، برنامه شروع نمی‌شود ولی لاگ
دقیقاً می‌گوید چه شد:

```
Buddy could not start: this Node.js is too old.

  running:  Node 20.11.0
  required: Node 22.5 or newer
```

> `node.version` تنها فیلدی است که از روی مستندات حدس زده شده، نه از فایل خودِ
> لیارا. اگر انتشار به این فایل ایراد گرفت، همین یک بخش را بردار — نسخه از
> `engines` در `package.json` هم خوانده می‌شود و لاگ در هر حال حقیقت را می‌گوید.

> اگر ساخت با خطای شبکه شکست خورد (npm در دسترس نبود)، `build.location` را از
> `iran` به جای دیگری عوض کن و دوباره منتشر کن.

## میان‌بر: بگذار اسکریپت انجامش دهد

مرحله‌های ۲ و ۴ (دیسک و متغیرها) را می‌شود به‌جای پنل، با یک فایل انجام داد.
روی **`setup-liara.bat`** دو بار کلیک کن.

این کار را می‌کند:

1. ابزار خط فرمان لیارا را نصب می‌کند (اگر نداشته باشی)
2. تو را به حساب خودت وارد می‌کند — رمزت فقط به لیارا می‌رود و هیچ‌جا ذخیره نمی‌شود
3. دیسکی به نام `data` می‌سازد
4. هر پنج متغیر را با املای درست ست می‌کند

**منتشر نمی‌کند.** برنامه‌ات به گیت‌هاب وصل است و لیارا خودش این کار را می‌کند.

اگر هنوز هوش مصنوعی لیارا را نخریده‌ای، آنجا که کلید را می‌پرسد سه بار Enter بزن؛
دو متغیری که به آن نیاز ندارند ست می‌شوند و بعداً می‌توانی دوباره اجرایش کنی.

اگر ترجیح می‌دهی همه‌چیز را دستی توی پنل بزنی، ادامه‌ی همین راهنما را بخوان.

## ۲. دیسک وصل کن

از بخش **دیسک‌ها** یک دیسک بساز و اسمش را بگذار:

```
data
```

**این قدم اختیاری نیست.** بدون دیسک، فایل پایگاه‌داده داخل خود کانتینر می‌ماند و
هر بار که دوباره منتشر کنی **همه‌ی حساب‌ها، گفتگوها و تکالیف پاک می‌شوند** — بی
هیچ خطایی، انگار سایت تازه نصب شده.

فایل `liara.json` که توی مخزن هست، دیسک را به این مسیر وصل می‌کند:

```
/app/data
```

اگر پنل مسیر دیگری نشان داد، همان را بردار و به من بگو تا `liara.json` و
`DB_PATH` را با آن هماهنگ کنم.

---

## ۳. هوش مصنوعی لیارا را بخر

**گوگل از سرور ایران در دسترس نیست.** هر کلید Gemini که بگذاری، روی لیارا هر
پیام با خطای «به سرویس هوش مصنوعی وصل نشدیم» برمی‌گردد — مشکل از کلید نیست، از
مسیر است.

پس سرویس **هوش مصنوعی لیارا** را فعال کن و از پنلش این سه چیز را بردار:

| چه چیزی | کجا استفاده می‌شود |
|---|---|
| کلید (API key) | `AI_API_KEY` |
| آدرس سرویس (base URL) | `AI_BASE_URL` |
| اسم مدل | `MODEL_ID` |

برنامه با هر سرویسی که فرمت «chat completions» اوپن‌ای‌آی را بفهمد کار می‌کند، و
لیارا همین فرمت را دارد. هیچ کدی لازم نیست عوض شود.

---

## ۴. متغیرها را بگذار

توی بخش **متغیرهای محیطی** این شش‌تا را اضافه کن:

```
NODE_ENV=production
AI_API_KEY=<کلید هوش مصنوعی لیارا>
AI_BASE_URL=<آدرس سرویس لیارا>
MODEL_ID=<اسم مدل>
```

> **`DB_PATH` لازم نیست.** مسیر پیش‌فرض خود برنامه دقیقاً همان‌جایی است که دیسک
> وصل می‌شود (`/app/data/study-buddy.db`)، پس یکی کمتر برای اشتباه
> نوشتن. اگر روزی دیسک را جای دیگری mount کردی، آن‌وقت این را هم اضافه کن.

همین که `AI_API_KEY` را گذاشته‌ای یعنی **هیچ کاربری لازم نیست کلید بخرد** — همه
از کلید تو استفاده می‌کنند. چیز دیگری لازم نیست. (کسی که بخواهد، همچنان می‌تواند
از تنظیمات کلید خودش را بگذارد.)

### ⚠️ دو چیزی که باید قبلش بدانی

**۱. از این به بعد پول همه‌ی کاربرها را تو می‌دهی.**
تنها چیزی که جلوی خرج شدن اعتبارت را می‌گیرد، محدودیت هر کاربر است — که الان
**۲۰ پیام در روز** و ۳ خلاصه‌ی ویدیو در ماه است. این عددها وقتی انتخاب شدند که
هر کاربر خودش پول کلیدش را می‌داد. حالا که کلید مال توست، عمداً تنظیمشان کن:

```
src/services/usage.js  →  PLAN_LIMITS
```

**۲. دو قابلیت روی سرور ایران کار نمی‌کنند**، چون هر دو به گوگل وصل می‌شوند:

- **گرفتن خودکار زیرنویس یوتیوب** — ولی جعبه‌ی «متن ویدیو را خودت بچسبان» کار
  می‌کند و مسیر اصلی حساب می‌شود، نه یک راه دوم.
- **ورود با گوگل** — اختیاری است و اگر تنظیمش نکنی اصلاً نشان داده نمی‌شود. ورود
  با ایمیل و رمز هیچ مشکلی ندارد.

## ۵. مخزن را وصل کن و منتشر کن

از گیت‌هاب این مخزن را وصل کن:

```
xboxmani1344/n
شاخه: claude/study-chatbot-four-phases-fujco0
```

لیارا خودش `npm install` و بعد `npm start` را اجرا می‌کند — چیزی لازم نیست تنظیم
کنی، هر دو توی `package.json` هستند.

## ۶. لاگ اولین انتشار را بخوان

برنامه موقع بالا آمدن می‌گوید با چه تنظیماتی دارد کار می‌کند. حالت سالم:

```
Buddy running at http://localhost:3000
  node      22.22.2
  database  /app/data/study-buddy.db  (on its own disk)
  ai        https://ai.liara.ir/...
  model     <اسم مدلت>
  shared    on — every signed-in user spends this key
```

سه چیز را از همین چند خط چک کن:

| خط | چه چیزی را ثابت می‌کند |
|---|---|
| `node 22.x` | نسخه درست است (باید ۲۲.۵ به بالا باشد) |
| `on its own disk` | **دیسک واقعاً وصل است** |
| `ai …liara…` | به سرویس لیارا وصل می‌شود، نه گوگل |

اگر به‌جای `on its own disk` نوشت `on the container filesystem`، این را هم زیرش
می‌بینی:

```
  WARNING: the database is not on a mounted disk.
  Every account, chat and task will be erased on the next deploy.
```

یعنی دیسک وصل نشده. الان که سایت خالی است ضرری ندارد، ولی قبل از اینکه کاربر
بگیری حتماً درستش کن.

و اگر اصلاً بالا نیامد، پیام خودش می‌گوید چه کار کنی:

| پیام | یعنی |
|---|---|
| `this Node.js is too old` | `liara.json` را نگاه کن، `node.version` باید `22` باشد |
| `the database folder is not writable` | مسیر دیسک با آنچه برنامه می‌خواهد نمی‌خواند |
| `SQLite is in "delete" mode, not WAL` | ایرادی نیست — فقط خبر می‌دهد دیسک شبکه‌ای است |

> کلید هوش مصنوعی هیچ‌وقت توی لاگ چاپ نمی‌شود، فقط اینکه ست شده یا نه. پس
> می‌توانی لاگ را بدون نگرانی برای من بفرستی.

## بعد از بالا آمدن

۱. برو روی آدرسی که لیارا داده و یک حساب بساز.
۲. یک جلسه‌ی درس شروع کن و یک پیام بفرست — این اولین چیزی است که ثابت می‌کند
   `AI_BASE_URL` و `MODEL_ID` درست‌اند.
۳. زبان را روی فارسی بگذار و دوباره یک پیام بفرست، تا ببینی مربی هم فارسی جواب
   می‌دهد.

بعد از آن، اگر خواستی دامنه‌ی خودت را وصل کنی، از بخش دامنه‌های پنل انجام می‌شود.
