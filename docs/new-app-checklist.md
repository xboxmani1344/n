# ساختن اپ جدید روی لیارا — چک‌لیست

ترتیبش مهم است. قدم اول همان چیزی است که این‌بار از دست رفت.

---

## ۱. اپ را بساز و **همان لحظه زیردامنه را فعال کن**

پنل لیارا ← اپ جدید ← **بلافاصله** برو توی بخش **دامنه‌ها** و زیردامنه‌ی
پیش‌فرض (`اسم-اپ.liara.run`) را روشن کن.

> **این کار مهلت دارد.** اگر توی هفته‌ی اول فعالش نکنی، برای همیشه از بین
> می‌رود و اپ فقط با دامنه‌ی اختصاصی در دسترس خواهد بود. دقیقاً همین اتفاق
> برای `buddyai` افتاد.

قبل از هر کار دیگری این را بزن. بقیه‌ی قدم‌ها عجله ندارند؛ این یکی دارد.

---

## ۲. دیسک بساز

بخش **دیسک‌ها** ← دیسک جدید:

| فیلد | مقدار |
|---|---|
| نام | `data` |
| مسیر | `/app/data` |

بدون دیسک، **هر بار که دیپلوی کنی همه‌ی حساب‌ها و گفتگوها پاک می‌شوند** —
بی‌صدا، بدون خطا. صفحه‌ی سلامت (قدم ۵) این را تشخیص می‌دهد و می‌گوید.

---

## ۳. متغیرها

حداقلِ لازم برای اینکه سایت بالا بیاید و چت کار کند:

| متغیر | مقدار |
|---|---|
| `NODE_ENV` | `production` |
| `DB_PATH` | `/app/data/buddy.db` |
| `AI_API_KEY` | کلید سرویس هوش مصنوعی‌ات |
| `AI_BASE_URL` | آدرس سرویس — **فقط یک `https://`** |
| `MODEL_ID` | اسم مدل، همان‌طور که پنل سرویس نوشته |
| `SHARED_API_KEY` | `1` (یعنی کلید تو خرج همه می‌شود) |

بقیه هر وقت خواستی:

| متغیر | برای چه |
|---|---|
| `APP_URL` | آدرس نهایی سایت — بازگشت از زرین‌پال و callback گوگل از این ساخته می‌شوند |
| `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` | ورود با گوگل |
| `SMTP_HOST` / `SMTP_PORT` / `SMTP_USER` / `SMTP_PASS` | ایمیل خوش‌آمد با کد تخفیف |
| `ZARINPAL_MERCHANT_ID` | پرداخت |
| `UNLOCK_ALL_TRACKS` | `1` یعنی همه‌ی مربی‌ها برای همه باز است. **قبل از پول‌گرفتن برش دار.** |

توضیح کامل هر کدام توی `.env.example` است.

## ۴. گیت‌هاب را وصل کن و دیپلوی بزن

مخزن `xboxmani1344/n`، برنچ `claude/study-chatbot-four-phases-fujco0`.

---

## ۵. صفحه‌ی سلامت را باز کن

اول یک حساب بساز (همین هم ثابت می‌کند دیتابیس می‌نویسد)، بعد:

```
https://آدرست/api/setup/health
```

همه‌چیز را یک‌جا می‌گوید: دیسک، آدرس، هوش مصنوعی، گوگل، ایمیل، پرداخت.
آخرش می‌نویسد چند چیز مانده. تا وقتی ننوشته **«Everything configured»**، کاری
مانده.

دو تای دیگر برای وقتی چیزی خراب است:

| آدرس | چه می‌گوید |
|---|---|
| `/api/setup/ai-check` | یک پیام واقعی می‌فرستد و می‌گوید کجای هوش مصنوعی خراب است |
| `/api/auth/google/redirect-uri` | دقیقاً همان رشته‌ای که باید توی Google Console ثبت کنی |

---

## ۶. گوگل، بعد از اینکه آدرس نهایی شد

Google Console ← همان OAuth client ← **Authorized redirect URIs** ← خروجی
`/api/auth/google/redirect-uri` را عیناً بچسبان.

آدرس که عوض شود این هم عوض می‌شود. گوگل حرف‌به‌حرف مقایسه می‌کند.

---

## درباره‌ی داده‌های اپ قبلی

حساب‌ها و گفتگوهای `buddyai` توی یک فایل SQLite روی دیسک همان اپ‌اند. اینکه
بشود بیرون کشیدشان بستگی دارد به اینکه پنل لیارا با دیسک چه اجازه‌ای می‌دهد —
از پشتیبانی بپرس.

اگر نشد، آن حساب‌ها از بین می‌روند. صادقانه: اگر هنوز کاربر واقعی نداشته‌ای،
ارزش معطل‌شدن ندارد — اپ جدید را بالا بیاور و جلو برو.
