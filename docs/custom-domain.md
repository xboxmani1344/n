# دامنه‌ی اختصاصی

الان سایت روی `buddyai.liara.run` است. این کار می‌کند، ولی زیردامنه‌ی پیش‌فرض مال
لیاراست — اگر روزی بخواهی جای دیگری میزبانی کنی، لینک‌هایی که پخش کرده‌ای می‌میرند.
دامنه‌ی خودت این را حل می‌کند.

## ترتیب کار — این ترتیب مهم است

### ۱. دامنه بخر

از هر ثبت‌کننده‌ای. برای `.ir` معمولاً ارزان‌تر است و با کارت ایرانی می‌شود خرید.
`buddyai.com` گرفته شده، پس دنبال یک ترکیب دیگر بگرد.

### ۲. در پنل لیارا اضافه‌اش کن

پنل → اپ Buddy → **دامنه‌ها** → دامنه را وارد کن. لیارا به تو می‌گوید چه رکورد DNS
بسازی (معمولاً یک `CNAME` یا `A`). آن را در پنل ثبت‌کننده‌ی دامنه بساز.

بعد صبر کن تا سبز شود. گاهی چند دقیقه است، گاهی چند ساعت — به DNS بستگی دارد نه به تو.

### ۳. `APP_URL` را عوض کن

**این مرحله را فراموش نکن.** این همان‌جایی است که یک سایت سالم بی‌صدا خراب می‌شود.

پنل → **متغیرهای محیطی** → `APP_URL` را بگذار روی آدرس جدید، با `https://` و
**بدون** اسلش آخر:

```
APP_URL=https://your-new-domain.ir
```

چرا مهم است: لینک بازگشت از درگاه پرداخت و آدرس callback گوگل هر دو از `APP_URL`
ساخته می‌شوند. اگر روی دامنه‌ی قدیمی بماند، هر دو **بعد از اینکه کاربر از سایت
خارج شده** شکست می‌خورند — سخت‌ترین جا برای دیدن خرابی. کسی که پول داده به صفحه‌ای
برمی‌گردد که وجود ندارد.

### ۴. redirect URI گوگل را دوباره ثبت کن

آدرس callback با دامنه عوض می‌شود، و گوگل آن را **کاراکتر به کاراکتر** مقایسه می‌کند.

آدرس دقیق را از خود اپ بگیر:

```
https://your-new-domain.ir/api/auth/google/redirect-uri
```

هرچه داد، همان را در Google Cloud Console → Credentials → OAuth client →
**Authorized redirect URIs** بگذار. آدرس قدیمی `liara.run` را هم فعلاً نگه دار تا
مطمئن شوی جدید کار می‌کند.

### ۵. چک کن

وارد شو و باز کن:

```
https://your-new-domain.ir/api/setup/health
```

اگر `APP_URL` با آدرسی که داری می‌خوانی نخواند، همین صفحه با خط قرمز می‌گوید. تا وقتی
آن خط هست، پرداخت و ورود با گوگل خراب‌اند.

## اگر چیزی کار نکرد

`‎/api/setup/health` اولین جایی است که باید نگاه کنی — آدرس، دیسک، کلید هوش مصنوعی،
گوگل، ایمیل و پرداخت را یکجا می‌گوید و هیچ رمزی را چاپ نمی‌کند، پس می‌شود اسکرین‌شاتش
را فرستاد.
